# Roadmap — Apparel by Ezekiel

## v1 (shipped)
Vite foundation, Supabase-ready data layer (IndexedDB offline adapter), public site with gallery, 3D preview (Beta), basic try-on (Beta), booking + WhatsApp, OPay demo notice, privacy page, PWA admin with Demo Login, orders, expenses and rule-based expense chat.

## Phase 2 targets (locked by owner, 3 Nov 2026)

### 1. Try-On Beta Polish ("Image 1" direction)
Realistic garment overlay on the user's uploaded photo: natural drape, soft lighting, and a clear **Order Now** button. Replaces the v1 placeholder try-on. Needs its own plan and review before building.

### 2. Simple CRM
Principles: extreme simplicity, progressive disclosure, only essential fields. Calm and premium.
- Minimal customer list: name, phone, status dot
- Add Customer: Name, Phone, Source only
- Measurements form: Chest, Waist, Hips, Shoulder, Sleeve
- Simple follow-up reminder: one card + Mark Done
- Customer profile with expandable sections: orders, measurements, notes

## Later (needs owner's yes)
Supabase project + schema applied, real Paystack/OPay deposits, AI expense parsing behind a server function.
